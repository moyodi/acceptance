# 홈페이지 제작 납품 확인서 생성기

홈페이지 제작 프로젝트의 **납품 확인서 / 개발 완료 및 검수 확인서**를 웹에서 작성하고
A4 PDF로 내려받거나 인쇄하는 도구입니다. 백엔드 없이 브라우저에서만 동작합니다.

- 웹 UI: MYD contract와 동일한 디자인 가이드(CRM Base Design System 토큰, Pretendard)
- 문서(PDF): 공식 비즈니스 문서용 단색 레이아웃

## 주요 기능

- 확인서 목록 — 여러 문서 생성·열람·복제·삭제(실행 취소), 발주사/프로젝트명 검색, 유형 필터
- 발주사·제작사 도장(서명) 이미지 첨부 — 문서의 (인) 자리에 표시, PDF에 투명 배경 그대로 포함
- 문서 유형 2종 (최종 납품 / 개발 완료 및 검수) — 제목·검수·최종 확인 문구 자동 전환, 유형별 수정 문구 보존
- 프로젝트·발주사·제작사 정보 입력 (미입력 선택 항목은 문서에서 숨김)
- 납품 항목 선택·이름 수정·추가·삭제·드래그 정렬(키보드 지원)
- 유지관리 기간·시작 기준·시작일(종료일 자동 계산)·조항 사용 여부, `{기간}` `{기준}` 치환
- 미완료 사항 및 특이사항 섹션 (표시/숨김, 작업·완료 예정일·비고, 추가 협의 내용)
- 실시간 A4 미리보기 (자동 페이지 분할, 확대/축소/맞춤)
- PDF 다운로드 — 한글 폰트 임베딩, 텍스트 검색·복사 가능 (`@react-pdf/renderer`)
- 브라우저 인쇄 — 문서 페이지만 출력
- 문서별 로컬 자동 저장 / 기본값(샘플) 불러오기 / 입력 내용 초기화 / 저장 데이터 전체 삭제
- 반응형: 데스크톱 2단, 모바일·태블릿은 편집/미리보기 탭

## 구조

```
src/
  lib/          데이터 타입, 기본 문구·샘플, 날짜/파일명, 로컬 저장(문서 목록), 해시 라우팅, 도장 이미지 처리, 필수값 검증
  pages/        목록 화면(#/), 편집 화면(#/doc/:id)
  doc/
    model.ts        입력 데이터 → 페이지에서 쪼개지지 않는 unit 목록
    layout.tsx      HTML·PDF 공용 레이아웃/스타일 (같은 정의를 양쪽에 렌더링)
    A4Preview.tsx   HTML 미리보기 + unit 높이 측정 기반 페이지 분할
    PdfDocument.tsx PDF 생성 (필요 시 지연 로딩)
  components/   편집 패널, 납품 항목 편집기, 공통 UI, 대화상자
public/fonts/   Pretendard (웹 UI와 PDF 임베딩에 공용)
```

미리보기와 PDF는 같은 unit 목록과 같은 스타일 정의를 사용하므로 줄바꿈과 페이지 분할이 일치합니다.
선 두께는 0.75pt(=1px) 배수만 사용합니다(1px 미만 선은 브라우저가 올려 그려 높이가 어긋남).

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 타입 검사 + 프로덕션 빌드 (dist/)
```

배포: Vercel (Vite 프리셋, 출력 디렉터리 `dist`).
